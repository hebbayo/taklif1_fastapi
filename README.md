# API مدیریت هزینه‌ها — نسخه ۲.۰.۰

## درباره پروژه

این پروژه تمرین عملی درس **«طراحی یک API مدیریت هزینه‌ها»** از دوره آموزش FastAPI در مکتب‌خونه است:

[مشاهده تمرین در مکتب‌خونه](https://maktabkhooneh.org/course/%D8%A2%D9%85%D9%88%D8%B2%D8%B4-%D8%B7%D8%B1%D8%A7%D8%AD%DB%8C-%D8%B3%D8%B1%D9%88%DB%8C%D8%B3-fastapi-mk10645/%D9%86%D8%B5%D8%A8-%D8%A7%D8%B3%D8%AA%D9%81%D8%A7%D8%AF%D9%87-fastapi-ch26667/%D8%AA%D9%85%D8%B1%DB%8C%D9%86-%D8%B7%D8%B1%D8%A7%D8%AD%DB%8C-%DB%8C%DA%A9-api-%D9%85%D8%AF%DB%8C%D8%B1%DB%8C%D8%AA-%D9%87%D8%B2%DB%8C%D9%86%D9%87%D9%87%D8%A7/)

در نسخه اصلی تمرین، داده‌ها فقط در حافظه (in-memory) نگه‌داری می‌شدند. در این نسخه (**v2.0.0**) پروژه ارتقا پیدا کرده و به جای حافظه موقت، از پایگاه داده **SQLite** برای ذخیره‌سازی دائمی هزینه‌ها استفاده می‌شود.

---

## تغییرات نسخه ۲ نسبت به تمرین اصلی

| ویژگی | نسخه اصلی (تمرین) | نسخه ۲ (این پروژه) |
|---|---|---|
| ذخیره‌سازی داده | در حافظه (list) | پایگاه داده SQLite |
| ماندگاری داده | پس از ری‌استارت از بین می‌رود | دائمی |
| مدیریت اتصال DB | — | `Depends(get_db)` با yield |
| راه‌اندازی خودکار DB | — | `lifespan` + `init_db()` |

---

## اندپوینت‌ها

| متد | مسیر | توضیح |
|---|---|---|
| `POST` | `/expenses` | ایجاد هزینه جدید |
| `GET` | `/expenses` | دریافت لیست همه هزینه‌ها |
| `GET` | `/expenses/{id}` | دریافت یک هزینه با شناسه |
| `PUT` | `/expenses/{id}` | ویرایش هزینه (partial update) |
| `DELETE` | `/expenses/{id}` | حذف هزینه |

## نصب و اجرا

```bash
pip install fastapi uvicorn
uvicorn expense_API:app --reload
```

پس از اجرا، مستندات تعاملی API در آدرس زیر در دسترس است:

```
http://127.0.0.1:8000/docs
```
